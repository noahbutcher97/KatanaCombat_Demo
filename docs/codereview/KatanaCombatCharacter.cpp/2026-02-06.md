## 6. Gaps & Bugs
### BUG-1: Camera Clipping (CAM-1)
*   **Priority**: 🟠 **High** | **Impact**: User Experience
*   **Description**: The `CameraBoom` has no ignored actors or custom collision channels. When the player is between multiple enemies (common in melee combat), the spring arm hits the enemy capsules and snaps the camera inside the player's head.
*   **Fix**:
    *   **Rationale**: The camera should only collide with the environment, not other pawns.
    *   **Snippet**:
        ```cpp
        CameraBoom->ProbeSize = 12.0f;
        // Option: Change probe channel to a custom 'Camera' channel that ignores Pawns
        CameraBoom->SetRelativeLocation(FVector(0, 0, 50)); // Lift pivot point
        ```

## 7. Action Items
*   **[Implementation]**: Modify `CameraBoom` collision settings to ignore the `Pawn` channel or implement a dynamic ignore list for nearby enemies.
