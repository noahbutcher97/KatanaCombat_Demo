# Code Review: DamageableInterface.h (2026-02-06)

## 1. Objective
Defines the public interface for actors that can take damage, be staggered, or perform finishers.

## 5. Key Areas
*   **Encapsulation**: Provides a clear contract for combat interaction, decoupling specific implementations from generalized combat logic.

## 6. Gaps & Bugs

### BUG-1: Deprecated Posture-related Interface Methods.
*   **Priority**: 🟠 **High** | **Impact**: API Cleanliness / Confusion
*   **Description**: Methods `ApplyPostureDamage`, `IsGuardBroken`, `GetCurrentPosture`, and `GetMaxPosture` are explicitly marked as `DEPRECATED` in the header. These methods are now dead code due to the removal of the posture system.
*   **Fix**: These methods should be physically removed from `DamageableInterface.h`. Interfaces define a contract; deprecated methods that do nothing or log warnings break that contract. If a new balance system is introduced, it should have a new, clearly named interface method.
    ```cpp
    // L34, L55, L85 (and others)
    -    UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Combat", meta = (DeprecatedFunction, DeprecationMessage = "Posture system removed. Use HitReactionComponent::ApplyStagger() instead."))
    -    bool ApplyPostureDamage(float PostureDamage, AActor* Attacker);
    +    // Removed: ApplyPostureDamage - Posture system deprecated.
    ```
