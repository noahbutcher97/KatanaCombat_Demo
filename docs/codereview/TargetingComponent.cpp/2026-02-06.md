## 6. Gaps & Bugs

### GAP-1: TArray Accumulation (Gap 18.20)
*   **Priority**: 🟡 **Medium** | **Impact**: Memory Bloat
*   **Description**: `PotentialTargets` array is not cleared if the character is disabled or dead, potentially holding stale actor references.
*   **Fix**: Call `PotentialTargets.Reset()` in `OnDeath` or `EndPlay`.

### GAP-2: Const Cast UB (Gap 22.9)
*   **Priority**: Low | **Impact**: Standards
*   **Description**: Uses `const_cast` in filter methods.
*   **Fix**: Refactor filter methods to be truly `const`.

### GAP-3: Hardcoded Log Categories for Counter Lock.
*   **Priority**: Low | **Impact**: Debugging
*   **Description**: The `LockToCounterTarget` and `ReleaseCounterLock` methods use `LogTemp` for their `UE_LOG` messages.
*   **Fix**: Use `LogTargeting` for consistency and easier filtering.
