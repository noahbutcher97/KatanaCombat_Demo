## 5. Gaps & Bugs

### GAP-1: Buffer Double-Dip Risk
*   **Priority**: 🟡 **Medium** | **Impact**: Accuracy
*   **Description**: `FDirectionalInputBuffer::CaptureDirection` overwrites the existing direction without checking if it was consumed. In ultra-rapid input scenarios, a release event could overwrite a direction that was just about to be processed.
*   **Fix**:
    *   **Rationale**: Protect discrete input events.
    *   **Action**: Add `bIsConsumed` flag to `FDirectionalInputBuffer`. Only allow `CaptureDirection` if the buffer is empty or marked as consumed.
