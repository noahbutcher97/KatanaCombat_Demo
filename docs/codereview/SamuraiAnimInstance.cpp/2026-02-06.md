# Code Review: SamuraiAnimInstance.cpp (2026-02-06)

## 1. Objective
Primary Animation Blueprint base class. Responsible for bridging the gap between C++ combat states and the AnimGraph locomotion/attack logic.

## 2. Scope
Native initialization, variable updates, and notify event routing.

## 3. Metrics & Standards
*   **Metrics**:
    *   Complexity: Medium.
    *   Test Coverage: Low (Requires visual regression tests).
*   **Standards Adherence**:
    *   Style & Naming: 🟢.
    *   Patterns: 🔴 **Technical Debt** (Incomplete wiring of critical combat states).

## 4. Code Organization
*   **Module Clarity**: High (Animation category).
*   **Component Cohesion**: High.
*   **Dependency Flow**: Standard (Depends on `Character` and `CombatComponent`).

## 5. Key Areas
*   **Functionality**:
    *   `UpdateMovement`: Standout implementation of "Locomotion Freeze" during attack holds. This prevents the character from switching to a "Run" pose while the attack montage is at 0.0 playrate.
    *   `UpdateHitReaction`: Dynamic intensity scaling for hitstuns.

## 6. Gaps & Bugs

### GAP-1: Missing Combat State Wiring
*   **Priority**: 🟠 **High** | **Impact**: Core Visuals
*   **Description**: `UpdateCombatState` and `UpdateCombo` are stubs with `TODO` comments. This means the AnimGraph never receives information about which attack phase is active or what the combo count is.
*   **Fix**:
    *   **Rationale**: State machine transitions in the AnimGraph depend on these variables.
    *   **Snippet**:
        ```cpp
        void USamuraiAnimInstance::UpdateCombatState() {
            if (UCombatComponent* Combat = GetCombatComponent()) {
                CombatState = Combat->GetCombatState();
                CurrentPhase = Combat->GetCurrentPhase();
                // ...
            }
        }
        ```

### GAP-2: Deprecated Posture System.
*   **Priority**: Low | **Impact**: Cleanup
*   **Description**: The `UpdatePosture` method's comment now reads `// DEPRECATED: Posture system removed. Keep defaults for backwards compat.`. However, the `bIsStaggered` variable is introduced to reflect the new stagger system, making the `PosturePercent` and `bIsPostureLow` variables functionally obsolete and purely for backward compatibility.
*   **Fix**:
    *   **Rationale**: To fully commit to the new stagger system, the deprecated posture-related variables (`PosturePercent`, `bIsPostureLow`) should be removed from the class, not just commented as deprecated. This cleans up the API and prevents accidental use.
    *   **Action**: Remove the `PosturePercent` and `bIsPostureLow` properties from `SamuraiAnimInstance.h`.
