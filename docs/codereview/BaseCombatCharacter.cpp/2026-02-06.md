*   **Priority**: 🟠 **High** | **Impact**: User Experience
*   **Status**: ✅ **FIXED** (5dc5dc3)
*   **Description**: Spring arm collision treated enemy pawns as obstacles.
*   **Fix Applied**: Added "Enemy" collision profile in `DefaultEngine.ini` that ignores `ECC_Camera`. `EnemyCharacter` sets this profile on BeginPlay.

### GAP-1: Lack of Hit Validation (HIT-1)

*   **Description**: `OnWeaponHitTarget` accepts all hits without verifying physical plausibility.
*   **Fix**:
    *   **Rationale**: Prevent "impossible hits" due to trace latency.
    *   **Snippet**: Implement distance-based hit rejection in `OnWeaponHitTarget`.

### GAP-2: Misleading `bWasCounter` population.
*   **Priority**: 🟡 **Medium** | **Impact**: Gameplay Logic
*   **Description**: The `HitInfo.bWasCounter = CombatComponent ? CombatComponent->IsInCounterWindow() : false;` line seems to incorrectly populate `bWasCounter`. `IsInCounterWindow()` checks if *this character* (the one being hit) is in *its own* counter window, which is incorrect for determining if the *incoming attack* was a counter.
*   **Fix**: This logic needs to come from the *attacker's* CombatComponent. As this is not straightforward from the current context, it should either be kept as false or passed correctly from the attacker.
    ```cpp
            HitInfo.AnimationTime = AnimInst->Montage_GetPosition(CurrentMontage);
    ```

### GAP-3: Deprecated Posture System Removal
*   **Priority**: Low | **Impact**: Cleanup
*   **Description**: The project is pivoting to a cinematic flow (AC3/Arkham). `ApplyPostureDamage`, `IsGuardBroken`, `GetCurrentPosture`, and `GetMaxPosture` are explicit deprecated in the `DamageableInterface` and their implementations now handle the removal.
*   **Action**: These methods should be physically removed from the interface and their implementations, as they are now dead code.

*   **Priority**: 🟠 **High** | **Impact**: Silent Failure
*   **Description**: The `ApplyPostureDamage_Implementation` function still returns `false`. If any legacy systems or new systems during transition call this, it will silently fail.
*   **Fix**: Log an error or warning, or to throw an assertion in `WITH_EDITOR` builds, to ensure that no code paths rely on this deprecated function.
    ```cpp
    bool ABaseCombatCharacter::ApplyPostureDamage_Implementation(float PostureDamage, AActor* Attacker)
    {
    // DEPRECATED: Posture system removed. If called, this indicates a legacy code path.

    }
    ```
