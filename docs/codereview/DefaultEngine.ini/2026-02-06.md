## 6. Gaps & Bugs

### BUG-1: Missing collision response for "Enemy" profile.
*   **Priority**: 🟡 **Medium** | **Impact**: Collision Issues / Unexpected Behavior
*   **Description**: The new "Enemy" collision profile defines `ObjectTypeName="Pawn"` but does not specify any `CustomResponses` for common collision channels like `WorldStatic` or `WorldDynamic`. This means it will use the default responses for `Pawn`, which might lead to unexpected blocking behavior against environmental elements or other dynamic objects, even though the help message states "Blocks everything except Visibility and Camera."
*   **Fix**: Explicitly define `CustomResponses` for common channels like `WorldStatic`, `WorldDynamic`, `Pawn`, `PhysicsBody`, etc., to ensure predictable collision behavior for the "Enemy" profile.
    ```ini
    +Profiles=(Name="Enemy",CollisionEnabled=QueryAndPhysics,bCanModify=True,ObjectTypeName="Pawn",CustomResponses=((Channel="WorldStatic",Response=ECR_Block),(Channel="WorldDynamic",Response=ECR_Block),(Channel="Pawn",Response=ECR_Block),(Channel="PhysicsBody",Response=ECR_Block),(Channel="Vehicle",Response=ECR_Block),(Channel="Destructible",Response=ECR_Block),(Channel="Visibility",Response=ECR_Ignore),(Channel="Camera",Response=ECR_Ignore)),HelpMessage="Enemy capsule that ignores camera collision (CAM-1 fix). Blocks everything except Visibility and Camera.")
    ```
