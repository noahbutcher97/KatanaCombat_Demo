## 6. Gaps & Bugs

### GAP-1: Lack of 2D/3D Toggle
*   **Priority**: 🟡 **Medium** | **Impact**: Targeting Consistency
*   **Description**: `FilterTargetsInCone` currently uses 3D distance, which can be undesirable in multi-level environments. Targets on a floor above can "steal" targeting priority from someone directly in front of the player if their 3D distance is slightly shorter.
*   **Fix**:
    *   **Rationale**: Melee combat usually operates on a 2D plane for distance priority.
    *   **Action**: Add a `bIgnoreZ` parameter to the query to allow 2D-only distance calculations.

### GAP-2: Missing Pre-Filter Callback
*   **Priority**: 🟡 **Medium** | **Impact**: Extensibility
*   **Description**: Queries iterate over all actors before checking relevance.
*   **Fix**:
    *   **Rationale**: Optimization for complex scenes.
    *   **Action**: Add a predicate delegate to allow early-out filtering (e.g., only check actors with specific tags or teams).
