## 6. Gaps & Bugs

### BUG-1: Semantic Ambiguity of `EFinisherTriggerReason::GuardBroken`.
*   **Priority**: 🟡 **Medium** | **Impact**: Code Clarity
*   **Description**: The code reuses `EFinisherTriggerReason::GuardBroken` to represent a `Staggered` state in `GetFinisherTriggerReason()`. While functional for backward compatibility, it introduces semantic ambiguity. `GuardBroken` implies a posture system, which is deprecated.
*   **Fix**: Introduce a new enum value for `EFinisherTriggerReason::Staggered` to clearly differentiate the new state from the old posture system.
    ```cpp
            // Priority 1: Staggered (replaces posture-based guard break)
            if (bIsStaggered)
            {
    -           return EFinisherTriggerReason::GuardBroken; // Reuse enum value for compatibility
    +           return EFinisherTriggerReason::Staggered; // New enum value for clarity
            }
    ```

### GAP-1: Delegate Leak Hazard (Gap 11.5)
*   **Priority**: 🟠 **High** | **Impact**: Memory
*   **Description**: `OnHitStunStarted/Ended` delegates are bound but never cleared.
*   **Fix**: Clear dynamic delegates in `EndPlay`.

### GAP-2: Redundant Tick Check in `TickComponent`.
*   **Priority**: 🟡 **Medium** | **Impact**: Code Clarity / Minor Performance
*   **Description**: The `SetComponentTickEnabled(false);` call has a redundant check `!IsComponentTickEnabled()`. The condition `if (!bIsStunned && !bIsStaggered && !bCurrentReactionHasIFrames)` covers whether tick *should* be disabled. The explicit check to see if tick *is already* disabled is unnecessary.
*   **Fix**: Simplify the tick management logic.
    ```cpp
        // Disable tick if nothing needs tracking
    -   if (!bIsStunned && !bIsStaggered && !bCurrentReactionHasIFrames)
    +   if (!bIsStunned && !bIsStaggered && !bCurrentReactionHasIFrames) // Only disable if no active states
        {
    -       SetComponentTickEnabled(false);
    +       SetComponentTickEnabled(false); // No need to check if already disabled
        }
    ```

### GAP-3: Reaction Suppression Ownership (SRP)
*   **Priority**: 🟡 **Medium** | **Impact**: Architecture
*   **Description**: Should be the sole owner of `bReactionsSuppressed` and `IsStunned` states.

### GAP-4: Missing History Variety (Gap 24.8)
*   **Priority**: 🟡 **Medium** | **Impact**: Visual Repetition
*   **Description**: Needs `FReactionHistory` to prevent playing the same hit reaction twice in a row (n-2 variety).
