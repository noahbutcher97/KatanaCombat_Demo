### BUG-1: Inverse Remaining Time Constraint
*   **Priority**: 🔴 **Critical** | **Impact**: Core Combat Feel
*   **Description**: `CalculateProceduralBlend` uses `FMath::Max` to constrain blend time to remaining animation. This forces the blend to be *at least* `MinBlend`, causing it to exceed duration.
*   **Fix**:
    *   **Rationale**: Blend duration must be a hard cap relative to available time.
    *   **Snippet**:
        ```cpp
        // Line 150
        if (BlendTime > Result.RemainingTime) {
            BlendTime = Result.RemainingTime; 
            Result.bRemainingTimeConstrained = true;
        }
        ```
    *   **Test Case**: `KatanaCombat.ProceduralAnimation.Advanced.BlendTiming.Edge.RemainingTimeConstraint`.
