## 6. Gaps & Bugs

### GAP-1: Hardcoded Class Dependencies (Gap 22.15)
*   **Priority**: 🟠 **High** | **Impact**: Fragility
*   **Description**: Uses `StaticLoadObject` with hardcoded string paths (e.g., `"/Game/VFX/..."`).
*   **Fix**: Move asset references to a **Developer Settings** class (`UCombatVFXSettings`) or use `TSoftObjectPtr` properties in a config asset.

### GAP-2: Inconsistent Log Categories.
*   **Priority**: Low | **Impact**: Debugging
*   **Description**: The new log messages (`[POOL-AUDIO] Tier 2 check:`, `[POOL-VFX] Tier 2 check:`) use `LogCombatFX` which is distinct from `LogCombat` used elsewhere in the project. Consistency in log categories is important for filtering and debugging.
*   **Fix**: Standardize log category to `LogCombat` or define `LogCombatFX` if it's truly a separate, specific subsystem.
    ```cpp
    // L364 and similar throughout
    -        UE_LOG(LogCombatFX, Log, TEXT("[POOL-AUDIO] Tier 2 check: CombatFXData=%s, AttackType=%d"),
    +        UE_LOG(LogCombat, Log, TEXT("[POOL-AUDIO] Tier 2 check: CombatFXData=%s, AttackType=%d"),
    ```
