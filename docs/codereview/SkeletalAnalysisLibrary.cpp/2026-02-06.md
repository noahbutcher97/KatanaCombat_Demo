## 6. Gaps & Bugs

### GAP-1: O(N^2) Recursive Bloat
*   **Priority**: 🟠 **High** | **Impact**: Performance
*   **Description**: `GetBoneChildren` with `bRecursive=true` performs a full subtree search for every node it encounters, leading to redundant traversals in deep hierarchies (e.g., finger chains).
*   **Fix**:
    *   **Rationale**: Linearize tree traversal.
    *   **Action**: Use an iterative stack/queue approach for recursive child gathering.

### GAP-2: Limited Support Polygon (Gap 18.21)
*   **Priority**: 🟡 **Medium** | **Impact**: AI Physics
*   **Description**: `CheckStability` assumes a bipedal 2-foot support polygon.
*   **Fix**: Update to support an arbitrary number of contact points (e.g., for quadrupeds or characters leaning on walls).

## 7. Action Items
*   **[Optimization]**: Refactor `GetBoneChildren` to be iterative.
*   **[Generalization]**: Expand `CheckStability` to accept a `TArray<FVector>` for the support polygon vertices.
