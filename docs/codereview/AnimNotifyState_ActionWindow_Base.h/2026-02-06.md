# Code Review: AnimNotifyState_ActionWindow_Base.h (2026-02-06)

## 1. Objective
Provides an abstract base class for explicit action windows (Hold, Parry, Combo, Cancel).

## 2. Scope
NotifyState interface and window type identification for checkpoint discovery.

## 5. Key Areas
*   **Design Analysis**: The use of an abstract base class with a `PURE_VIRTUAL` `GetWindowType()` is an excellent application of the **Template Method Pattern**. It allows the `MontageUtilityLibrary` to discover all windows polymorphically without knowing their specific types.

## 6. Gaps & Bugs

### GAP-1: Discovery Overhead
*   **Priority**: Low | **Impact**: Performance
*   **Description**: `DiscoverCheckpoints` must scan all notifies.
*   **Fix**: This is generally performed once per montage load, so the impact is minimal.
