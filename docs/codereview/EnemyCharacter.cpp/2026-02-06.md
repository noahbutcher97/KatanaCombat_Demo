## 6. Gaps & Bugs

### BUG-1: Hardcoded Collision Profile Names.
*   **Priority**: 🟡 **Medium** | **Impact**: Maintainability
*   **Description**: The lines `GetCapsuleComponent()->SetCollisionProfileName(TEXT("Enemy"));` and `GetMesh()->SetCollisionProfileName(TEXT("EnemyMesh"));` use hardcoded string literals for collision profile names.
*   **Fix**: It is better practice to retrieve collision profile names from a centralized configuration (e.g., a `UDataAsset` or `UCombatSettings`) to improve maintainability and prevent typos.
    ```cpp
        // CAM-1 FIX: Use "Enemy" collision profiles that ignore camera
        // This prevents the spring arm from colliding with enemies
    -   GetCapsuleComponent()->SetCollisionProfileName(TEXT("Enemy"));
    -   GetMesh()->SetCollisionProfileName(TEXT("EnemyMesh"));
    +   // Consider using FName constants or retrieving from CombatSettings for maintainability.
    +   GetCapsuleComponent()->SetCollisionProfileName(FName("Enemy"));
    +   GetMesh()->SetCollisionProfileName(FName("EnemyMesh"));
    ```

## 7. Action Items
