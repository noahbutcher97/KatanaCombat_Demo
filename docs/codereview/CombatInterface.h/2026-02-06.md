*   **Priority**: 🟡 **Medium** | **Impact**: Debugging
*   **Description**: Calls to `Execute_` functions fail silently if the target doesn't implement the interface.
*   **Fix**: Use `Cast<ICombatInterface>` and log a warning if a critical combat message is sent to a non-combatant.

### GAP-2: Posture System Removal
*   **Priority**: Low | **Impact**: Cleanup

*   **Action**: These should be removed or refactored to reflect the new AC3/Arkham-style combat.
