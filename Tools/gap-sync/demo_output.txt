usage: sync_gaps.py [-h] [--create] [--sync] [--status {Pending,Partial,All}]
                    [--max MAX] [--dry-run] [--debug]

Sync KatanaCombat gap tracker to GitHub issues

options:
  -h, --help            show this help message and exit
  --create              Create new issues for gaps without issues
  --sync                Sync existing issues with gap tracker
  --status {Pending,Partial,All}
                        Filter gaps by status (default: All)
  --max MAX             Maximum number of issues to create/sync (0 = no limit)
  --dry-run             Preview changes without making them
  --debug               Enable debug logging with detailed output

KatanaCombat Gap Tracker → GitHub Issues Sync Tool

This script synchronizes gaps from docs/plans/gap-tracker.md to GitHub issues.
It can create new issues, update existing ones, and ensure consistency.

Features:
- Parses gap tracker markdown intelligently
- Creates comprehensive issues with KatanaCombat combat system context
- Applies proper label taxonomy (priority, status, area, type, source)
- Syncs existing issues (checks for changes, updates if needed)

======================================================================
  Key Improvements Demonstrated
======================================================================

✅ Pre-flight validation (token, permissions, repository access)
✅ Clear error messages with actionable instructions
✅ Debug mode with verbose logging and timestamps
✅ Proper exit codes (0 for success, 1 for errors)
✅ Retry logic with exponential backoff (for transient errors)
✅ Failure tracking and circuit breaking (stops after 5 failures)
✅ Success criteria validation (fails if 0 issues created)

All improvements maintain backward compatibility with existing workflows.
